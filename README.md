#Manim Projects

This repository contains my projects built using Manim, a mathematical animation engine used to visualize concepts in mathematics, physics, and computer science.

Purpose

The goal of these projects is to turn abstract concepts into clear visual explanations. I use animation to better understand and communicate ideas such as motion, functions, and geometric relationships.

What You'll Find
Mathematical visualizations (functions, graphs, transformations)
Physics-based animations (motion, vectors, basic simulations)
Experimentation with animation techniques and scene construction
Project Structure

Each folder contains:

Source code for the animation
A description of the concept being demonstrated
Instructions to run the scene (if needed)
Example Topics
Function transformations
Projectile motion
Trigonometric relationships
Graphing and coordinate systems
Tools Used
Python
Manim
VS Code
